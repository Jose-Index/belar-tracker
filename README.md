# BELAR Tracker v9

Portfolio tracker personal — Capa JOSE · Ecosistema IA Personal

## Stack
- Next.js 14
- Supabase (PostgreSQL)
- Recharts
- Tailwind CSS
- Vercel

## Setup
1. `npm install`
2. Copy `.env.local.example` to `.env.local` and fill in Supabase credentials
3. `npm run dev`

## Deploy
Connected to Vercel via GitHub. Push to `main` triggers auto-deploy.
